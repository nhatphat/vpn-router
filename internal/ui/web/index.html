forced through VPN

Destinations that must never be reached directly, whatever the racer decides. Matching is by Host and TLS/QUIC SNI for domains, and by executable for processes. sing-box reloads this file itself, so nothing needs restarting.

scoped resolvers

Suffixes macOS resolves through vpnctl, by way of a file in /etc/resolver. Switching one off removes that file and keeps the entry; removing it takes the entry out of the config too. Each change is applied by the daemon straight away.
